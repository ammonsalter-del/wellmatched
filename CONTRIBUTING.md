# Contributing

Suggestions, experiments and experiences, positive or negative, are welcome.

- **Tried it?** Tell the developer what worked and what did not: [ammon.salter@wbs.ac.uk](mailto:ammon.salter@wbs.ac.uk), or open an issue.
- **Found a mistake?** Open an issue with the page, what you did, and what it told you. Please do not include your API key, your CV or anyone's personal details.
- **Want to change it?** Fork the repository and open a pull request. The development manual (`manual.md`) explains how the tool works, how it scores and the rules it follows.
